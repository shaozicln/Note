# Vue3 和 Vue2 的主要区别

1. Vue2 和 Vue3 **双向绑定** 方法不同
    **Vue2 : Object.defineProperty()**   
            后添加的属性是劫持不到的            
    **Vue3 : new Proxy()**        
            即使后添加的也可以劫持到
            还不需要循环
            直接代理整个对象，支持动态新增/删除属性，无需特殊API，对数组操作更友好，本身就能监听到数组变化

2. 是否支持碎片，vue3支持，vue2不支持，必须对整体包装一个根元素

3. $set在vue3中没有set用于解决数据更新了但是视图没更新的问题；因为new Proxy不需要   

4. 关于写法  
    vue2是选项式API，用this.xxx；
    vue3可以向下兼容（选项式API），也可以组合式api或Setup语法
    糖形式，需要用另外的方式获取上下文数据
    vue3的setup在组件初始化的时候就被触发了，reactive初始化然后template获取这些数据 

5. 生命周期不同，vue3创建生命周期就是setup，挂载是onMounted和onUnmounted, onbeforeUpdate和onupdated

6. 传值不同
    vue2用

7. v-if和v-for优先级不同了

    2.x版本中，`v-if` < `v-for` 

    3.x版本中，`v-if` > `v-for` 

8. $ref和$children也不同
