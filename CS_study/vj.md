#### E、黑匣子（对顶堆、Hard）

 对顶堆，小根堆对大根堆，其实本质上是不停add中间穿插了几次get

在没有到达当前get命令（u值）之前，不停的add

对顶堆：

```c
// 大根堆，正三角，最上面的根（q1.top()）最大
priority_queue<int> q1;
// 小根堆，倒三角，最下面的根（q2.top()）最小
priority_queue<int, vector<int>, greater<int>> q2;
```

add过程：

```c
while(pos < u){
		pos++; // 计数
        q1.push(a[pos]); // 插入大根堆，并且筛出i个数中的最大值，踢出最大值弹给小根堆，将自己变成前i-1个最小数
     // 插入小根堆排序，不断add但是要维护大根堆数据个数，也就是“每次add都将前pos个数中的第i小的数放在q2.top()”
		q2.push(q1.top());
		// cout << q1.top() << ' ';
		q1.pop();
}
```

get过程：

```c
 cout << q2.top() <<endl; // 输出小根堆根，因为当前的大根堆q1一定是i-1个数
// 还给大根堆排序，继续用于下一次add-get判断
 q1.push(q2.top()); // 大根堆q1变成i个数
 q2.pop();
```

#### F、Favorite Game（排序代价计算）

本质上是计算拥有m个元素的字串范围在a[1]和a[2]之间的时候，这两个数变化的代价是什么

先排序a[3] ~ a[n]

代价判断：

```c
sort(a.begin() + 3, a.end());
for (int i = 3; i <= n - m + 1; i++) {
        int res = 0; //代价计算
        int l = a[i], r = a[i + m - 1];
        if (l < a[1]) res += a[1] - l;
        if (r > a[2]) res += r - a[2];
        ans = min(ans, res);
}
cout << ans << endl;
```
