```c
#include <stdio.h>

int main() {
    double x, m;
    scanf("%lf %lf", &x, &m);
    double n = x / m;
    //首项x 尾项0 项数 x/m + 1
    double S = (n + 1) * x / 2;
    printf("%.2lf\n", S);
    return 0;
}
```


#### NANA的旅行计划

​	NANA得到宝藏离开【main】山四处旅游。对于NANA来说，世界太大了，但她觉得国外的月亮或许也没有那么圆。于是NANA决定先制作一份国内旅行计划。NANA不太熟悉电脑操作，请你帮帮NANA实现以下效果：

​	每个旅行地点都有自己的信息，包括地名、票价、分类等。现在NANA想要进行m次查询，每次查询第i个地点的某一个信息。其中查询地名操作为Name，查询省份操作为Province，查询类型操作为Type

```plaintext

接下来n行：每一行输入旅行地点的名称(Name)、省份(Province)、类型(Type)，中间用空格隔开。
然后输入一个正整数m表示接下来进行m次查询
接下来m行：每一行输入查询的地点编号i和将要查询的信息名称
数据范围：1<=n<=1000，名称、票价、类型的长度保证在1-100之间，1<=m<=1000


输出
m行输出，每一行输出查询的地点信息
```



```plaintext
样例输入
3
Imperial_Palace Beijing Humanities
West_Lake ZheJiang Lake
Everest Tibet Mountain
3
1 Type
2 Name
3 Province
样例输出

West_Lake
Tibet
```



#### NANA的旅行经费

​	NANA毫无节制0收入的四处旅游，让曾经拥有很多【宝藏】的她濒临破产了。现在NANA需要在这个地方打工来赚取自己接下来的旅行经费。和NANA一起打工的是NANA旅行中结识的一些伙伴。**过了一个冬天和一个春天之后**，老板告诉大家所有人的工资将上涨25%，但是老板还不舍得给能干的员工很高的工资，于是他规定：最高工资5000，所有人不可超过该工资。

​	输入NANA和伙伴们的信息，请设计一个结构体储存这些信息，并设计一个函数模拟工作和涨工资过程，其参数是这样的结构体类型，返回同样的结构体类型，并输出员工信息。



```plaintext
输入格式
第一行输入一个正整数 n，表示员工个数。
第二行开始往下 n 行。每行首先是一个字符串表示员工姓名，再是一个整数表示员工年龄，再是一个整数为去年工资。

输出格式
输出 n 行，每行首先输出一个字符串表示姓名，再往后两个整数，表示经过一年的打工后大家的年龄和他们涨薪后的工资。以空格隔开。

输入输出样例
输入 
3
NANA 20 3600
ChenYu 23 3100
Venti 2600 4200

输出
NANA 21 4500
ChenYu 24 3875
Venti 2601 5000
```



```c
#include<bits/stdc++.h>
using namespace std;
struct Salary {
	string name;
	int age, salary;
} a[100000];

int main () {
	int n;
	cin >> n;
	for (int i = 1; i <= n; i++) {
		cin >> a[i].name >> a[i].age >> a[i].salary;
		a[i].age++, a[i].salary = a[i].salary * 1.25;
		if (a[i].salary > 5000) a[i].salary = 5000;
		cout << a[i].name << " " << a[i].age << " " << a[i].salary << endl;
	}
	return 0;
}
```
